AI Portfolio Chatbot
This site. A retrieval-augmented chatbot built over my own resume, projects,
and skills - documents are chunked, embedded with the Gemini embedding API,
indexed in FAISS, and retrieved at query time so answers stay grounded in
real source material instead of the model guessing. Built with FastAPI,
React, and Tailwind CSS.

RecruitIQ - HR Analytics & Attrition Prediction
Developed an interactive HR analytics dashboard using Python, Streamlit, and
Plotly, performing comprehensive EDA and feature engineering to visualize
workforce trends across multiple demographic filters. Implemented a Random
Forest ML model to predict employee attrition, integrating it with
rule-based logic to automate promotion and retrenchment rate calculations
for data-driven HR decision-making. Engineered a multi-page, filter-driven
interface with drill-down analysis and deployed the final application on
Hugging Face Spaces for cloud-based accessibility.
GitHub: github.com/YASH-MV/Recruit_IQ

Dsa-Analyser - AI-Driven DSA Optimization Platform
Engineered a full-stack platform utilizing the Google Gemini Pro API to
provide automated static code analysis and time/space complexity feedback,
establishing a foundation for intelligent code evaluation. Architected a
Spring Boot RESTful API integrated with JWT authentication and MySQL,
ensuring secure, stateless session management and persistent tracking of
user problem-solving histories. Built an automated feedback loop that mimics
real-world interviews by delivering structured efficiency scores and
targeted refactoring suggestions.
GitHub: github.com/YASH-MV/Dsa_Analyser
